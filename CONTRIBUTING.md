# Contributing

Thank you for your interest in contributing to Nimploy!

## Development Setup

```bash
# Install dependencies
pnpm install

# Start backend development server
pnpm dev:server

# Start frontend development client
pnpm dev:client
```

## Testing & Quality Checks

```bash
# Run test suite
pnpm test

# Run typecheck and builds
pnpm build
pnpm typecheck

# Run linter/formatter check
pnpm check
```
