# Agent Instructions & Guidelines

## UI & Design Rules
- **Shadcn UI Components Only**: Always use shadcn/ui components for all UI elements. If shadcn/ui does not have a component that matches the requirements, confirm with the user before adding or implementing a custom non-shadcn/ui component.
- **No Marketing Fluff or Boilerplate Subtitles**: Never add unnecessary marketing buzzwords, boilerplate slogans, decorative badge fluff, or obvious explanatory subtitle text under headers/page titles (e.g., "Autonomous Micro-PaaS Engine", "Ultra-Low Footprint Mode", "Group and manage your microservices, APIs, and background workers.").
- **Clean & Minimal UI**: Keep UI headers, navigation bars, and page titles clean, direct, and functional. Avoid adding placeholder taglines or redundant helper text unless explicitly requested.
- **No Redundant Card Explanations/Action Links**: If an entire card is clickable, do not add redundant "Open Project ->", "View Details ->", or "Click to view" links/buttons inside the card to explain that it opens.
